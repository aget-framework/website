# AGET home

The public AGET landing page at **https://www.aget.dev/**.

This is a dependency-free static site. GitHub Pages publishes the repository root from `main`; `CNAME` assigns the custom domain to this project site.

To preview locally, run `python3 -m http.server 8000` and open `http://localhost:8000`.

Framework source and documentation: https://github.com/aget-framework/aget.
