# AGET home

The public AGET landing page at **https://www.aget.dev/**.

This is a dependency-free static site. GitHub Pages publishes the repository root from `main`; `CNAME` assigns the custom domain to this project site.

To preview locally, run `python3 -m http.server 8000` and open `http://localhost:8000`.

Framework source and documentation: https://github.com/aget-framework/aget.

## First-session trial

The home includes an explicit macOS/Linux local-template trial: clone with the default folder name, create a Python environment, install requirements, run template checks, then open the same folder in a coding assistant for a read-only wake-up/explanation. This is not a personalized supervisor setup or a claim of measured newcomer independence.
